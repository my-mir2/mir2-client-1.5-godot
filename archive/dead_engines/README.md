# 归档的死代码 (dead_engines)

本目录是从生产源码中移出的 **34 个 `Official*100DetailsEngine`** (约 1.6 万行) 及其 **34 个测试文件** (1541 个测试方法)。

## 为什么归档
- 这些引擎在 `src/` 内**没有任何生产引用**，只被各自的一个测试文件引用。
- 测试验证的是“孤立小函数自己算对”，并不代表服务端/客户端真的按此运行，因此**不得计入官方 1.5 还原度**。
- 2026-10 全量审计时发现：测试总数 2440 中 1541 个 (63%) 属于此类。

## 如何恢复
全部通过 `git mv` 移动，历史完整。恢复: `git mv archive/dead_engines/src/<file> src/Mir2.Shared/Rules/` 与对应测试。
若其中某个细节确有价值，应当把它**接入生产路径并用走生产路径的测试覆盖**，而不是原样搬回。
