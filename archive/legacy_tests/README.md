# 归档的旧测试 (legacy_tests)

本目录是 2026-10 清理时从 `tests/CSharp/` 移出的全部旧单元测试 (除 `TestOfficialWorldFromDatabase`)。

## 为什么归档
- 其中约 40% 只调用孤立的静态引擎函数，约 30% 手工构造场景后直接调 `Dispatch`，真正走 TCP 的也是手摆场景。
- 它们长期给出“全绿”的错觉，却**从未发现**以下真实游戏问题（无头机器人第一次游玩就暴露）：
  城镇守卫攻击善良玩家把 1 级角色打到 1 点血；每次击杀凭空多出一个官方没有的“<怪物名>_战利品”；多次拾取无服务端确认。
- 现在以 `tools/Mir2.Bot` 无头玩家机器人作为唯一的行为验证手段：它只讲线协议、只信服务端下发的包，像玩家一样走完整流程。

## 如何恢复
全部通过 `git mv` 移动，历史完整: `git mv archive/legacy_tests/<file> tests/CSharp/`。
若要重新启用某个测试，请先确认它走的是生产路径，并且验证的是玩家可感知的结果。
