## 四、消息格式（实证）
### 服务端 → 网关（AA55AA55）
```
offset 0x00: 0xAA55AA55 魔数
offset 0x10: dword 消息长度
offset 0x0A: word 协议号
offset 0x14: 消息体
```
### 客户端消息
```
消息构造函数 fcn.00458d3c: offset4=协议号(word), offset0=数据指针
```

## 五、使用方法
- 双端 A 级 SM（50 个）为最高优先级，应优先在 Rust 中实现/核验
- B 级（服务端发）需确认客户端为何不处理 → 可能是扩展消息
- C 级（客户端收）需确认服务端是否发送 → 可能是待补全

## 六、复现
```bash
# 客户端 CM 发送
r2 -q -c "aaa; axt fcn.00458d3c" MIR_final_v3_p.exe
# 客户端 SM 接收
r2 -q -c "aaa; s fcn.00481dd4; pd 20000" MIR_final_v3_p.exe | grep -oE "(cmp|mov) ..., 0x[0-9a-f]+"
# 服务端 SM 发送
r2 -q -c "aaa; s fcn.004d68d0; pd 20000" M2Server.exe | grep -oE "(cmp|mov) ..., 0x[0-9a-f]+"
```
