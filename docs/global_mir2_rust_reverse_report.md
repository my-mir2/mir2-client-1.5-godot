# 热血传奇 1.5 (mir2-rust) 全局核心系统逆向与实证报告

## 报告摘要
本报告基于对 `mir2-rust` 服务端源代码的深度白盒审查，结合与官方 Delphi 原版代码（`M2Server` 等）的交叉比对，系统性揭露了该架构在战斗、爆率、经验分配、惩罚机制上的底层数学真相，并披露了数个破坏游戏平衡的重大漏洞。

---

## 第一部分：被戳破的老玩家玄学神话

### 1. 垫刀玄学：不存在的“周期性好运”
- **代码真相**：在 `item_upgrade.rs` 中，武器升级的成败完全取决于最后取出试刀时的一个独立随机数 `rand(0, 100) < user_luck_chance`。没有任何代码记录了所谓的“上一次碎刀”或“垫刀序列”。**每一刀的概率都是绝对独立的**。
- **系统设定**：放入超过 5 块矿、超过 2 件首饰对成功率或持久保留没有任何额外帮助，溢出部分被系统直接丢弃。

### 2. 运9加爆率：幸运值完全不干扰极品掉落
- **代码真相**：玩家击杀怪物后生成装备的 `generate_mon_random_add_value` 函数入口处，**根本没有传入玩家的 `luck` 变量**。极品的附加属性（+1 攻击等）完全基于独立写死的静态概率分布（例如千分之一的极品率）。高幸运只负责物理/魔法攻击的上限投点。

### 3. 宝宝吸经验：主人的全额白嫖
- **代码真相**：当道士的骷髅或神兽打出最后致命一击时，事件系统会通过 `slaves.get()` 寻址，强制把“击杀权”完全上抛给主人。法师/道士**将毫无损耗地获得 100% 的击杀经验**。

### 4. 大护身符加火符伤害、高道术绿毒更疼
- **代码真相**：绿毒的掉血量（11点/跳）和红毒的易伤系数（1.2倍）被完全硬编码，**彻底屏蔽了玩家自身道术（SC）的加成**。护身符仅仅在开火前扣除 1 点持久，其自身的任何属性都不会混入“灵魂火符”的最终伤害公式。

## 第二部分：惊天底层漏洞与硬编码灾难

### 1. 双时间戳脱机瞬移漏洞 (P0)
- **机制还原**：原版传奇强制使用单一变量限制全局移动（600ms）。而 `mir2-rust` 创造性地分离了 `last_walk_tick` 和 `last_run_tick` 两个独立计时器。
- **利用方式**：黑客只需向服务端连续发送“走 (Walk)” + “跑 (Run)” 的封包组合，能在 10ms 内无视所有速率墙，连续跨越 3 个网格，实现瞬移。

### 2. 敏捷套彻底失效 BUG (P0)
- **机制还原**：躲避公式 `rand(0, speed_point) < hit_point` 要求攻击者准确率低于防御者躲避率。
- **问题爆发**：由于配置表丢失了怪物的真实准确率参数，作者在 `respawn.rs` 极其草率地硬编码了 `HitPoint = MonsterLevel * 2 + 5`。导致 40 级怪拥有高达 85 点准确。玩家哪怕堆砌神级敏捷套（30点敏捷），依然满足 `rand(0, 30) < 85` 恒成立，导致怪物对玩家**100% 绝对命中**。

### 3. 组队经验倒挂漏洞 (P1)
- **机制还原**：系统对组队存在 `1.3x ~ 2.2x` 的全局经验膨胀池。为了平衡高低级差异，使用了 `Level/SumLevel` 按比例分配，并用 `raw_exp`（单怪原始经验）作为单人获取的绝对上限。
- **利用方式**：“40级大号带10级小号”，大号计算得出的分配经验是 `1.04倍`，触碰上限后截断为 `100%`。大号的经验**一分不少**，而小号无条件白嫖 26% 的凭空产出。

### 4. 彻底报废的 60 血“纸糊变异骷髅” (P2)
- **机制还原**：对于法师宝宝和神兽，均有完善的等级随动放大代码。唯独在 `MagicEffect::Summon` 的变异骷髅分支中，写死了 `HP = 60`。无论道士的召唤骷髅技能练到几级，骷髅永远只有 60 点血量，彻底失去实战价值。

---

## 结论
`mir2-rust` 服务端在框架与网络同步上达到了极高的完成度，但在核心数值模型（尤其是怪物参数、宠物成长、毒药公式）上存在大量图省事的暴力“硬编码”行为，并且为了拆分业务流，引发了双计时器瞬移等新时代的安全漏洞。本项目目前极具二次开发与修复重构的价值。
